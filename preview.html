把背景调暗一点

你
背景的 gif 挺好看的，但正文字有点压不住。能不能让它只做气氛，别抢读？
Assistant

可以。做法是把它当成“水面”而不是“壁纸”：图像先模糊一层，再压一道渐变遮罩，最上面的面板只留一点透明，于是水只在对的地方透出来。

  • 模糊遮掉 400×225 放大后的颗粒
  • 遮罩把顶部压亮、底部压暗，视线自然落在中段
  • 面板只留 24% 不透明度，水在底色里走，字在板上读
  • 选中的行不是变色，而是一块 斜切蓝板滑进来
  • 对话框照游戏来：你的白底蓝字，它蓝底白字
.water { filter: blur(2.5px) brightness(.9); opacity: 1; }
body::before { background: navy tint, .26 → .42; }
--dsw-alias-bg-base: rgba(10, 22, 46, 0.24);
